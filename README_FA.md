# Gold Bar Android

نسخه اندروید فایل `Golde Bar1-1.xlsx` با رابط RTL مشکی/طلایی.

## منطق منتقل‌شده از اکسل

- ثبت چند آبشده با «ردیف/شماره راهنما»، وزن و عیار.
- جمع وزن هر ردیف و محاسبه عیار میانگین وزنی.
- فرمول شمش مورد نیاز:
  - اختلاف عیار = عیار ریخته‌گری - عیار میانگین آبشده
  - مورد نیاز = عیار شمش - عیار ریخته‌گری
  - شمش مورد نیاز = `ROUNDDOWN((وزن × اختلاف عیار) / مورد نیاز, 1)`
- فرمول بار ریخته‌گری:
  - کل بار = `وزن × عیار آبشده / عیار ریخته‌گری - وزن`
  - نقره = `درصد نقره × کل بار`
  - ۰.۴٪ = `کل وزن همه آبشده‌ها × 0.004` (عین مرجع N3 اکسل)
  - بار نهایی دیگر = `کل بار - نقره - ۰.۴٪`
- ابزار ۳۶.۷۹٪ / ۶۳.۲۱٪.
- ابزار اصلاح وزن مطابق فرمول سلول W10 اکسل.

## قابلیت‌ها

- رابط فارسی RTL و پوسته مدرن مشکی/طلایی.
- انتخاب شماره راهنما و محاسبه جداگانه هر ردیف.
- افزودن، ویرایش و حذف آبشده‌ها.
- ذخیره خودکار داده‌ها در خود گوشی با SharedPreferences.
- بازیابی ۷ ردیف نمونه موجود در فایل اکسل.
- پشتیبانی از اعداد فارسی و انگلیسی در ورودی‌ها.
- بدون نیاز به اینترنت و بدون کتابخانه شخص ثالث.

## ساخت در Android Studio

پروژه را در Android Studio باز کنید و Gradle Sync را اجرا کنید. پروژه از AGP 8.13.2، Java 17 و compileSdk 36 استفاده می‌کند.

سپس:

`Build > Build APK(s)`

خروجی معمولاً در مسیر زیر قرار می‌گیرد:

`app/build/outputs/apk/debug/app-debug.apk`

## ساخت و تست خودکار با GitHub Actions

Workflow مسیر `.github/workflows/android.yml` با JDK 17، Android SDK رسمی، Gradle 8.13 و AGP 8.13.2 اجرا می‌شود. ابتدا فرمول‌های اصلی اکسل را assert می‌کند، سپس APK Debug را می‌سازد و بعد آن را روی Android Emulator نصب و `MainActivity` را باز می‌کند. اگر فرایند برنامه بعد از اجرا زنده نباشد، متن `GOLD BAR` در UI دیده نشود یا `FATAL EXCEPTION` در logcat دیده شود، workflow شکست می‌خورد. APK فقط در صورت وجود واقعی به عنوان Artifact آپلود می‌شود.
